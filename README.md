# Kolir — Portfolio Showcase (Upwork-safe)

Мінімальний Next.js-застосунок, який показує **лише портфоліо**: каталог робіт і
сторінку кожного кейса (англійською). Жодних інших сторінок, контактів, соцмереж,
переходів на основний сайт чи в зовнішні ресурси. Призначено для показу робіт на Upwork.

Тут немає ні Payload/CMS, ні бази даних, ні бекенду — тільки статичні дані кейсів
(`src/data/cases.ts`) і картинки в `public/`.

## Що всередині
- `/portfolio` — каталог кейсів (фільтри/сортування).
- `/portfolio/<id>` — сторінка окремого кейса.
- Будь-який інший шлях (у т.ч. `/`) редіректиться на `/portfolio` (`src/proxy.ts`).
- Хедер — лише лого; футер — лого + копірайт (без соцмереж/контактів).
- Усі сторінки `noindex`, мова — англійська.

## Запуск
```bash
npm install
npm run build
npm start        # http://localhost:3000  → /portfolio
```
Для розробки: `npm run dev`.

## Деплой
Це SSR-застосунок (через proxy-редіректи) — потрібен Node-раннер:
- **Vercel:** імпортувати папку як проєкт, білд-команда `npm run build` (дефолт). Env не потрібні.
- **Свій сервер:** `npm ci && npm run build && npm start`.
Домен — нейтральний (не kolir).

## Оновлення портфоліо
Кейси описані в `src/data/cases.ts` (+ картинки в `public/images/<case>/`).
Показуються лише кейси з англомовними картинками (UA-only кейси приховані).
